# 简日记 JianRiJi

一个自己重写的日语学习 iOS App：艾宾浩斯背单词、查词、五十音、听写。

> **这件事得先说清楚**：App Store 上的上架包拿不到，也不存在「反编译一个 iOS 版」这种路径。所以这个仓库是**照着玩法重新实现的原创工程**——没有「识日」的任何代码、词库、图标或界面素材，UI 与数据结构都是自己写的。想用，就自己编译；想上架，就自己签名。

## 构建

要求：**Xcode 15+**、iOS 16.0+、[XcodeGen](https://github.com/yonaskolb/XcodeGen)。

```bash
brew install xcodegen
git clone https://github.com/lpdada/JianRiJi.git
cd JianRiJi
xcodegen generate
open JianRiJi.xcodeproj
```

不想装 XcodeGen 也行：

1. Xcode 里 New Project → iOS App，名字填 `JianRiJi`，Interface 选 SwiftUI。
2. 把 `JianRiJi/` 下所有 `.swift` 拖进工程（记得勾 Copy items if needed）。
3. 把 `Resources/seed_words.json`、`Info.plist`、`Assets.xcassets` 一起拖进去，确认 `seed_words.json` 在 Build Phases 的 Copy Bundle Resources 里。
4. Bundle Identifier 改成你自己的，签名选自己的 Team。

真机跑之前去「设置 → 辅助功能 → 朗读内容 → 声音 → 日语」下一个语音包，不然发音会退回默认语言。

## 词库

`Resources/seed_words.json` 是一个数组，字段：

```json
{
  "id": "w001",
  "term": "学校",
  "reading": "がっこう",
  "romaji": "gakkou",
  "meaning": "学校",
  "pos": "名词",
  "jlpt": "N5",
  "example": "学校まで歩いて十分です。",
  "example_zh": "走到学校十分钟。"
}
```

`example` 和 `example_zh` 可省。`id` 必须全局唯一——记忆进度是跟着 `id` 走的，改 `id` 等于换了一张新卡。`example_furigana` 可省：分段式（如「数学[すうがく]が」）经典模式按段标读音与 romaji，整句式（如「がっこうはえきのちかくです。」）整句显示读音与 romaji。

当前词库共 **10660 条**：N5 803 / N4 755 / N3 1827 / N2 3216 / N1 4059。

- 主词库 10641 条：来自 [5mdld/anki-jlpt-decks](https://github.com/5mdld/anki-jlpt-decks)（作者 egg rolls），许可证 **CC BY-NC 4.0**，仅限非商业使用、须署名。本 App 目前不收费、不商用，符合该许可；以后如果要商用，必须先把这部分词库换掉。
- 精讲 150 条：自编，131 条覆盖了主词库里的同词同读音（覆盖后保留主词库 id，释义 / 例句 / 词性以精讲为准，解析进详情页「解析」区块），19 条是主词库没有的，直接追加。33 条词的级别以精讲为准、与主词库原级别不同（例如「習慣」主词库 N3、精讲 N4）。
- romaji 由假名自动生成（已用旧 80 条种子校验：79/80 与原 romaji 一致，唯一一处是「じゅんび」用 n 不用 m；外来语音节如 ふぁ→fa、てぃ→ti、ちぇ→che 已处理）。片假名词的读音字段原本是英文（如 bed），已改用词形本身转假名（如 べっど / beddo）。
- 主词库里同词同读音有 9 组重复（不同释义），全部保留，id 不同所以不会互相顶掉。
- 122 条词没有「例」标签的例句，详情页不显示例句区块，不是缺数据。
- **注意**：从旧 80 条种子版升级过来，旧卡的记忆进度不会自动带过来——进度是跟着 id 走的，id 全换了，新词库从新卡开始。

## 已知限制

- 没有笔顺动画。手写识别已做（学习页「手写」模式，Vision ja-JP，画布手写、内存图片识别）。
- 变形规律 14 章全文还没进 App：目前只有词条详情页的变形表 + 语法学习 270 条，变形规律的系统讲解仍在网页学习系统里。
- 没有 AI 查词、没有语音识别打分。
- 单机存档：删 App 即清空，导出/导入还没做。
- 只在 SwiftUI 原生 iOS 16+ 上验证过设计，iPad 是能跑但没专门排版。
